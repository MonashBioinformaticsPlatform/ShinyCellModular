# Package index

## Core functions

Prepare a Seurat object on disk, generate the modular Shiny app from it,
and scaffold a new module template.

- [`prepShinyCellModular()`](https://monashbioinformaticsplatform.github.io/ShinyCellModular/reference/prepShinyCellModular.md)
  : Prepare a Seurat object for ShinyCellModular
- [`useShinyCellModular()`](https://monashbioinformaticsplatform.github.io/ShinyCellModular/reference/useShinyCellModular.md)
  : Generate a modular ShinyCellModular Shiny app
- [`templateShinyCellModular()`](https://monashbioinformaticsplatform.github.io/ShinyCellModular/reference/templateShinyCellModular.md)
  : Create a template file for a new ShinyCellModular module/tab
